- 2026-11-23: Hang fix. A live eval hung ~53 min on one coder request: an established connection to Google with no answer, although the client timeout (NEXURA_LLM_TIMEOUT_S=120) was set, so the library timeouts do not reliably stop a stalled connection. `agents.llm.call_with_deadline` now runs every model call (coder/debugger via `invoke`, planner via `_call_with_retry` and `call_text`) in a daemon thread with a hard deadline NEXURA_LLM_HARD_TIMEOUT_S (default 2 x timeout + 30 = 270 s, above the client's own timeout x its internal retry so a slow but alive call is not cut). On expiry it raises a "timed out" error, which the existing transient-error logic retries with backoff and counts in the usage budget; after LLM_MAX_ATTEMPTS the call fails as LLM_UNAVAILABLE. A stalled thread cannot be killed: it is abandoned (daemon, so it never blocks exit) and may hold a socket until the OS closes it. Tests use a scripted model that blocks on an Event. First measured live hang cause was not identified beyond "no response on an open connection".
